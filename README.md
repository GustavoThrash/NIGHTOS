# NIGHTOS

App pessoal (PWA) estilo Cyberpunk: Comprar, Tarefas e Agenda.

## Publicar no GitHub Pages
1. Extraia o ZIP (o GitHub não extrai sozinho).
2. Crie um repositório no GitHub e envie os arquivos da pasta (Add file > Upload files). Inclua o arquivo oculto `.nojekyll` se possível.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. Abra o link `https://SEUUSUARIO.github.io/NOMEDOREPO/` no Safari do iPhone.
5. Compartilhar > Adicionar à Tela de Início.

## Observações
- Os dados ficam salvos no aparelho. Use SISTEMA > Exportar backup de vez em quando.
- Instalado na tela inicial, o app tem armazenamento separado do Safari: use sempre o ícone.
